Real Israeli town names for OpenTTD.
Town name style(s) in this NewGRF: {styles}

How to use
1. In the main menu, open NewGRF Settings and activate "{title}".
2. Start a new game and pick the style in the "Town names" list.
3. The style is fixed when the map is created. Existing games keep theirs.

Hebrew letters show as boxes or question marks?
Open Game Options > Graphics and turn off "Use traditional sprite font",
so OpenTTD uses a system font that has Hebrew letters.
